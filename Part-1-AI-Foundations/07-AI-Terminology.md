# 07. AI Terminology

AI has many terms. This chapter gives simple meanings for the words you will see throughout the book.

## Model

A program with learned parameters. It receives input and returns output.

## Training

The process of teaching or improving a model using data.

## Inference

The process of using a trained model to answer a request.

## Token

A piece of text used by a language model. A token may be a word, part of a word, punctuation mark, or space.

## Context Window

The maximum amount of text the model can consider at one time.

## Prompt

The input sent to a language model. It may include instructions, examples, user messages, documents, and tool results.

## Completion

The text generated by the model.

## Latency

How long a request takes from start to finish.

## Throughput

How much work a system can complete in a period of time.

## Batch

A group of requests processed together to improve hardware usage.

## GPU

A processor designed for many parallel numerical operations. GPUs are commonly used for deep learning.

## Quantization

Using smaller number formats to reduce memory and sometimes increase speed.

## Embedding

A vector of numbers that represents meaning. Embeddings are often used for search and retrieval.

## Hallucination

An output that sounds plausible but is false or unsupported.

## Developer Checklist

- Learn token, context, latency, throughput, and batch early.
- Ask whether a term refers to model behavior, hardware, or serving software.
- Do not let unfamiliar vocabulary hide simple ideas.
