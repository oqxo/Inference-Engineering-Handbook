# Glossary

## Activation

Temporary values created while a neural network processes input.

## Attention

A transformer mechanism that lets tokens use information from other tokens.

## Batch

A group of requests processed together.

## Context Window

The maximum amount of input and generated text the model can consider.

## Decode

The inference phase where output tokens are generated one at a time.

## Embedding

A vector representation of meaning.

## GPU

A processor designed for highly parallel numerical work.

## Inference

Using a trained model to answer a request.

## KV Cache

Stored attention data used to avoid recomputing previous token information.

## Latency

The time a request takes.

## Model

A learned program that maps input to output.

## Parameter

A learned number inside a model.

## Prefill

The inference phase where the model processes the input prompt.

## Prompt

The input sent to a language model.

## Quantization

Using smaller numerical formats to reduce memory or improve speed.

## Sampling

The process of choosing generated tokens from model probabilities.

## Token

A piece of text used by a language model.

## Throughput

The amount of work completed over time.

## Training

The process of creating or improving a model using data.
